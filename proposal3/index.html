Calibration sessions, so the graders stop drifting

Distributed reviewers drift. You measure the drift on known cases before you trust any number they produce.

The dead-knob test and the plateau rule

Before tuning a parameter, prove it does anything: a sweep producing byte-identical trades is a dead knob. A supported value comes from a plateau of at least three points, never from the edge of the tested range. A sweep never applies a value; the operator does.

research/sweep.py

Escalation that fails safe instead of guessing

An unexplained variance gets stopped and raised. It does not get a plausible assumption and a green checkmark.

Reconciliation halts on anything it cannot explain

ADR-0005: orphaned positions are adopted at real cost basis or not at all. There is no probably fine branch. The rule exists because a predecessor's orphan-flattener skipped its own exclusion when a file was merely absent, and flattened the whole account.

ADR-0005

Decision documentation for audit

Auditors do not ask what you chose. They ask what you rejected, and why, and when. An undocumented decision is an unmade one.

An autonomous paper-trading platform for US equities over the Webull OpenAPI. Architecture

One process is the structural chokepoint (ADR-0002). Strategies are pure functions of a bar window and never touch a broker, a clock or the database. That is what makes a new strategy incapable of bypassing safety, sizing or the order lifecycle, and what makes the same code run identically in backtest and live.

Four excerpts, unedited, from the repository above. These are the ones that show judgment rather than syntax.

src/webull_trading/safety/endpoints.py

The control with no override. The comment explains why, which is the part that survives a refactor.

"""§2: live trading is structurally unreachable, not merely non-default.

The allowlist below is deliberately a code-level frozenset with no env-var
override. Enabling live trading requires a committed edit to this file (and
to the test that pins it).
"""

ORDER_CAPABLE_ENDPOINTS = frozenset({"api.sandbox.webull.com"})

SANDBOX_TRADE_ENDPOINT = "api.sandbox.webull.com"


class SafetyError(Exception):
    pass


class EndpointNotOrderCapableError(SafetyError):
    pass


def assert_order_capable(endpoint: str) -> None:
    if endpoint not in ORDER_CAPABLE_ENDPOINTS:
        raise EndpointNotOrderCapableError(
            f"endpoint {endpoint!r} is not order-capable; "
            f"allowlist: {sorted(ORDER_CAPABLE_ENDPOINTS)}"
        )
src/webull_trading/agents/strategy.py

The contract that makes a new strategy incapable of bypassing safety, and makes backtest and live provably the same path.

"""The Strategy contract (ADR-0007).

A Strategy is a *pure function of a bar window*: on every bar close of a
ticker it receives a ``TickerView`` — bars for any universe symbol and
timeframe, the ticker's FSM state, its setup, its open position — and
returns one ``Decision``. It never sees a database, a broker, an order
engine, or a clock; the runtime owns every side effect. That is what
makes a generated Agent unable to bypass safety, the order lifecycle,
persistence, or the risk layer — and what makes the same Strategy run
identically through the backtest and live paths (§7.12).

The FSM the runtime enforces (spec §4)::

    FLAT ──Watch──▶ WATCHING ──Arm──▶ ARMED ──Enter──▶ IN_POSITION
      ▲               │ Reset          │ Reset            │ stop fill /
      └───────────────┴────────────────┘                  │ Exit / flatten
      ◀────────────── COOLDOWN (cooldown bars, loss streak) ◀┘

Decisions outside the current state's row are rejected and recorded,
never applied. Stops a Strategy proposes pass through the risk layer's
floor at entry and the ratchet afterwards. Sizing is not the Strategy's
to decide; it may only scale its risk budget down (``risk_scale``).
"""
src/webull_trading/risk/limits.py

Guardrails as pure decisions over persisted state, so a restart cannot reset a kill switch. Note the last line: calibration guidance kept deliberately out of the code.

"""Account-level guardrails (spec §8, §7.11): the day's loss budget, the
giveback limit off ``peak_equity``, loss-streak cooldowns, and the
concurrency cap. Pure decisions over numbers the runtime reads from
``agent_day_state`` — the persisted, restart-surviving kill-switch
state (§6). Calibration guidance, not code: set the daily loss limit
~1.8× the worst backtested day once history exists.
"""

from dataclasses import dataclass
from decimal import Decimal


class LimitParamError(ValueError):
    pass


@dataclass(frozen=True)
class LimitParams:
    daily_loss_fraction: Decimal
    giveback_fraction: Decimal
    giveback_min_gain: Decimal
    max_open_positions: int
    ticker_loss_streak: int
    book_loss_streak: int

    def __post_init__(self) -> None:
        if not 0 < self.daily_loss_fraction < 1:
            raise LimitParamError("daily_loss_fraction must be in (0, 1)")

03  /  The method

Rules the code is not allowed to contradict.

A predecessor system was retired for applying the opposite of the evidence, automatically, every week. Its tuner could only raise entry selectivity, while widening stops turned out to be the winning lever twice. Before writing a line of the replacement I distilled that history into rules with section anchors. The plan, the ADRs and every module are written against them. Six of the fourteen:

§7.1

Prove a knob does something before tuning it.

Four of seven agents' score gates were non-functional: a dead code path, zero outcome correlation, never binding, or a field that did not exist. Weeks of tuning moved nothing. A sweep producing byte-identical output is the cheapest test in existence.

§7.7

Win rate without expectancy is meaningless.

The old research grid contained an 83.4% win rate that loses money, profit factor 0.63, manufactured trivially by barrier geometry: a wide stop and a tight target. A number that geometry alone can produce is not a result.

§7.12

Backtest and live must share the exact same exit and sizing functions.

The best backtest, profit factor 1.11 to 1.18, went 0.54 live over 134 trades. Every divergence source turned out to be measurable and boring: unmodeled slippage at 0.024% per fill, enough on its own to invalidate every prior tuning decision; a session window mismatch; no portfolio-level state; and ATR computed 27 to 38% larger live.

§7.11

Circuit breakers sit outside the backtested distribution.

About 1.8 times the worst observed day, plus a hard notional cap independent of all sizing logic. A limit derived from the same distribution it is meant to protect you from is not a limit.

§7.13

Short samples find regimes and dress them as effects.

A gap-fade showed 22.6 basis points per day across a 33-session archive and was negative over ten years. The convenient window is the one that flatters you.

§7.14

Retiring a strategy is a legitimate outcome. A refuted hypothesis is a good week.

This is the hard one to hold, and it is the one seventeen years of audit work taught me. The pressure is always to find something. The discipline is reporting that there was nothing there.

No build step, no framework

One HTML file, self-hosted font subsets, one JSON file. No bundler, no npm install, nothing to rot. The complexity budget went into the trading platform, where it earns something.

Zero third-party requests

The typefaces are subset and served from this host, so the page makes no request to any origin but its own. No CDN outage, no font-provider telemetry, no flash of unstyled text.

The starfield is O(n), not O(n²)

Linking nearby stars naively costs a comparison per pair. This one bins stars into a uniform grid sized to the link radius and checks only the four forward neighbor cells, so each pair is considered once. It also respects prefers-reduced-motion and stops animating on a hidden tab.
